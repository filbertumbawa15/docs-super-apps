# Aset gambar

Taruh file resmi di sini (tidak disertakan di repo):

- `logo/polri.png` – logo di avatar header dashboard (persegi, latar transparan).
- `discovery/1.png` – poster Discovery kiri (potret, mis. 600x900).
- `discovery/2.png` – poster Discovery kanan (potret).
- `profile/foto.jpg` – foto profil pengguna (avatar dashboard dan atribut foto VC).

Bila file tidak ada, aplikasi menampilkan placeholder bergaya sama.
