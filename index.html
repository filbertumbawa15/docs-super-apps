API Lookup Pengajuan SKCK & Izin Keramaian

Satu endpoint untuk mengambil profil singkat pemohon beserta riwayat pengajuan SKCK dan Izin Keramaian berdasarkan NIK. Dipakai oleh aplikasi eksternal yang sudah punya App-Id dan Access-Key.

POST/api/v1/external/service-applications/lookup

Mulai cepat #

  1. Minta APP_ID dan Access-Key ke pengelola API.
  2. Kirim request POST berisi NIK ke endpoint lookup.
  3. Baca data.user, data.skck, dan data.crowd_permit dari respons, lalu tampilkan.
curl -X POST "$HOST/api/v1/external/service-applications/lookup" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json" \
  -H "App-Id: $APP_ID" \
  -H "Access-Key: $ACCESS_KEY" \
  -d '{"nik":"0000000000000001","page":1,"per_page":20}'

Autentikasi #

Setiap request wajib membawa dua header identitas. API ini tidak memakai skema Bearer.

HeaderWajibIsi
App-IdwajibAPP_ID aplikasi pemanggil yang terdaftar.
Access-KeywajibToken akses, dikirim apa adanya tanpa awalan Bearer.
Content-Typewajibapplication/json
Acceptdisarankanapplication/json

Jangan taruh Access-Key di frontend produksi. Siapa pun bisa membaca header dari browser. Panggil API ini dari backend Anda, lalu teruskan hasilnya ke halaman.

Endpoint lookup #

POST{{host}}/api/v1/external/service-applications/lookup

Mengembalikan profil pemohon dan daftar pengajuan untuk NIK yang dikirim. Layanan yang tidak diminta tetap ada di respons sebagai array kosong, jadi bentuk respons selalu sama.

pageintegeropsionalNomor halaman. Default 1.

Struktur respons #

Respons memakai amplop standar. Isi utama ada di data, paginasi di info.

FieldTipeKeterangan

codeintegerKode HTTP, mis. 200.
timestampstringWaktu respons, zona WIB (+07:00).
message.titlestringJudul pesan, mis. "Pengajuan Layanan".
message.descriptionstringDeskripsi, mis. "Lookup pengajuan selesai".
data.userobject | nullid (integer) dan full_name. Bernilai null jika NIK tidak punya akun.
data.skckarrayDaftar objek SKCK.
data.crowd_permitarrayDaftar objek izin keramaian.
infoobjectLihat paginasi.

Objek SKCK #

FieldTipeKeterangan
idstring (ULID)ID pengajuan.
registration_numberstringNomor registrasi.
statusstringSalah satu dari status SKCK.
submitted_atstringWaktu pengajuan, ISO 8601 UTC (Z).
purposestringKeperluan, mis. "Pekerjaan".
print_locationstringLokasi cetak, mis. "Polres Contoh".
classificationstringKlasifikasi, mis. "DALAM NEGERI".
application_pathstringPath dokumen PDF SKCK, relatif terhadap host.

Objek izin keramaian #

FieldTipeKeterangan
idintegerID pengajuan. Perhatikan: berbeda tipe dengan ID SKCK.
registration_numberstringNomor registrasi.
statusstringStatus pengajuan, mis. schedule_confirmed.
submitted_atstringWaktu pengajuan, ISO 8601 UTC.
activity_namestringNama kegiatan.
activity_type_namestringJenis kegiatan.
requested_review_datestring (tanggal)Tanggal peninjauan yang diminta, YYYY-MM-DD.

Paginasi #

info berisi current_page, per_page, total, dan last_page. Nilai total adalah gabungan SKCK dan izin keramaian. Contoh: 1 SKCK + 1 izin keramaian menghasilkan total: 2.
